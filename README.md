# Saját Boltom 3D (munkanév)

3D bolt-menedzser mobiljáték a 2015-ös „Én kicsi Tescóm” (My Little Tesco) mintájára, de annál jobb.

## Cél
- Saját bolt felépítése és berendezése 3D-ben: polcok rácsra pakolása, áthúzása, dekoráció.
- Árurendelés, polcfeltöltés, árazás.
- Sétáló vevők útkereséssel, kosár, sorban állás, kasszák.
- Forgatható, nagyítható kamera.
- Offline is játszható, a barátos funkciók később.
- Magyar felület.

## Technika
- Motor: Godot 4 (GDScript).
- Platform: Android (APK, Gradle export), Linux.
- Csak szabadon használható (CC0) modellek, például Kenney.

## Szabályok
- Tesco- vagy más védjegyes név, logó, arculat nem használható.
- Aláírókulcs, jelszó, token nem kerülhet a repóba (lásd .gitignore).
